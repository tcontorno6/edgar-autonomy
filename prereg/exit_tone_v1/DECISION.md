# Decision: stop after Phase 0 (2026-10-22)

The owner decided to publish the Phase 0 result and not to run the test on Ford. The owner's
reason: Ford can only be scored by switching from the pre-registered view (robotaxi-service
passages outside risk factors and legends) to the all-autonomy view, because the pre-registered
view has no data for it. That would change the method so that the test could run, which is the
same move that made the original wind-down list circular.

- No Phase 1 rule was committed. Phases 2 and 3 were not run.
- No tone was computed for Ford. The Ford count files on the Desktop (`data\exit_tone_v1\`) hold
  passages and word counts only, no Loughran-McDonald counts.
- Sequence, for the record: at 22:14 UTC the owner picked "Ford only, broader view" on a decision
  card; at 22:16 UTC the owner replaced that with this decision. Nothing was run in between.

Result: the GM tone drop in Finding 05 could not be tested out of sample on these three exits
with the method it rests on. It remains a single, retrospective case whose 2023Q4 cut was read
off the series.
